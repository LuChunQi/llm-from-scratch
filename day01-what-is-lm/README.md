## 1. 从一个游戏开始：文字接龙

你一定玩过"词语接龙"——我说"苹果"，你说"果树"，我说"树上"……

但想象一个更高级的版本：**我给你一句话的前半段，你来猜下一个字**。

```
我说：  "今天天气真"
你猜：  "好" （概率 70%）
你猜：  "棒" （概率 15%）
你猜：  "差" （概率 10%）
你猜：  "的" （概率 3%）
你猜：  "狗" （概率 0.01%）
```

你几乎不假思索就选了"好"，因为你脑子里有一个超级强大的模型——你读了二十多年中文，见过无数"天气真好"的搭配，知道"好"是最自然的接续。

**语言模型就是在做这件事。** 它量化了"下一个词是什么"的概率。

---

## 2. 语言模型的数学定义

语言模型的目标很简单：**给一段文本 $w_1, w_2, ..., w_n$ 算出一个概率**，表示这段话"有多像人话"。

用数学表达：

$$P(w_1, w_2, ..., w_n) = P(w_1) \cdot P(w_2|w_1) \cdot P(w_3|w_1,w_2) \cdot ... \cdot P(w_n|w_1,...,w_{n-1})$$

看起来很唬人？别怕，我们拆开看。

### 2.1 链式法则：连乘就是全概率

这句话说的是一个常识：**一堆事情同时发生的概率 = 每件事依次发生的条件概率相乘**。

举个例子：

```
"我 爱 中 国" 这句话的概率 =

P("我")                    → "我" 出现的概率
× P("爱"|"我")             → 前面是"我"时，"爱"出现的概率
× P("中"|"我爱")           → 前面是"我爱"时，"中"出现的概率
× P("国"|"我爱中")         → 前面是"我爱中"时，"国"出现的概率
```

每一项都是"在已知前面所有词的情况下，下一个词出现的概率"。这就是条件概率。

### 2.2 所以语言模型的核心问题是什么？

**核心问题：给定前面的词 $w_1, ..., w_{t-1}$，预测下一个词 $w_t$ 的概率分布。**

也就是计算 $P(w_t | w_1, w_2, ..., w_{t-1})$。

一旦你能算这个，你就能：
- **生成文本**：每次挑概率最高的词（或按概率随机采样），不断往后接
- **判断句子合理性**：把每个词的条件概率乘起来，越接近 1 越像"人话"
- **做纠错、翻译、摘要……** 几乎所有 NLP 任务的基础

---

## 3. 掷骰子模型 🎲

现在用"掷骰子"来理解条件概率。

想象你有一枚**超级骰子**——它不是正六面体，而是有 N 个面，每个面是一个汉字。但这个骰子是**有记忆的**：

- 如果你刚掷出了"天"，骰子会变身，让"气""空""下"这些面变大
- 如果你刚掷出了"天气"，骰子再变，让"预""真""很"这些面变大
- 如果你刚掷出了"天气真好"，骰子几乎只剩下"啊""，""。"几个大面

**这就是条件概率的可视化**——历史不同，骰子的面大小（概率分布）就不同。

语言模型 = 根据历史文本，动态调整骰子各面大小的方法。

---

## 4. N-gram：最经典的语言模型

### 4.1 核心思想

精确计算 $P(w_t | w_1, ..., w_{t-1})$ 需要考虑所有历史，这太复杂了。

**N-gram 的捷径：只看前面 N-1 个词就够了。**

| 模型 | 名称 | 预测依据 | 公式 |
|------|------|----------|------|
| Unigram | 一元模型 | 不看历史 | $P(w_t)$ |
| Bigram | 二元模型 | 看前 1 个词 | $P(w_t \| w_{t-1})$ |
| Trigram | 三元模型 | 看前 2 个词 | $P(w_t \| w_{t-2}, w_{t-1})$ |

这就是**马尔可夫假设**：未来只依赖于最近的有限历史。

### 4.2 怎么算？数一数就知道了！

以 Bigram 为例，预测 $P(\text{"好"} | \text{"真"})$：

$$P(\text{好}|\text{真}) = \frac{\text{"真好" 出现的次数}}{\text{"真" 出现的总次数}}$$

就这么简单！**统计历史文本中，"真"后面接"好"的比例**。

用伪代码表示：
```python
# 统计语料中 "真好" 出现的次数
count("真好") = 50
# 统计语料中 "真" 出现的总次数（后面接任何字）
count("真") = 200
# 条件概率
P("好"|"真") = 50 / 200 = 0.25
```

### 4.3 完整的 Bigram 语言模型训练过程

1. **收集语料**：准备大量文本（书籍、新闻、网页……）
2. **分词**：把文本切成词或字
3. **统计频次**：数每个 bigram（词对）出现了多少次
4. **算概率**：用频次除以总数，得到条件概率
5. **预测/生成**：根据概率选下一个词

配套代码 `ngram_lm.py` 实现了这个完整流程，你可以直接运行。

## 5. N-gram 的致命问题

N-gram 简单有效，但有几个严重缺陷：

### 5.1 稀疏性问题（Sparsity）

假设你的语料里从来没出现过 "量子" 后面接 "纠缠"（因为你只用新闻语料训练），那 $P(\text{纠缠}|\text{量子}) = 0$。

**没见过 ≠ 不可能。** 但 N-gram 会认为概率为 0，整个句子的概率就变成 0 了。

> **类比**：你从没吃过榴莲，不代表榴莲不能吃。你只是没见过而已。

**缓解方法**：平滑（Smoothing），给没见过的组合分一点小概率。比如最简单的 Laplace 平滑：

$$P(w_t|w_{t-1}) = \frac{\text{count}(w_{t-1}, w_t) + 1}{\text{count}(w_{t-1}) + V}$$

其中 $V$ 是词汇表大小。但这只是创可贴，不是根治。

### 5.2 短视问题（Short Context）

Bigram 只看 1 个词，Trigram 只看 2 个词。但语言中的依赖可以非常远：

```
"我 [省略 100 个字] 的那只猫，昨天 ______"
```

你要填空，必须看到 100 字前的"猫"。但 Trigram 根本看不到那么远。

提高 N 会怎样？比如用 5-gram？

- 参数量爆炸：$V^5$ 种组合（$V$ 是词汇量，中文常用字 3000，$3000^5 = 2.4 \times 10^{17}$）
- 稀疏性更严重：绝大多数 5-gram 在语料中根本没出现过

**这是死胡同。** N 不能太大。

### 5.3 无泛化能力

N-gram 本质上是"死记硬背"——它只能记住见过的搭配。

- 它不知道"猫"和"狗"都是动物（语义相似性）
- 它不知道"跑得快"和"飞得快"结构相同（句法泛化）
- 它只是数数，不理解任何含义

> **类比**：N-gram 就像一个只背了答案但没理解原理的学生，换个考法就不会了。

## 6. 从统计到神经网络：语言的第二次革命

N-gram 的所有问题，核心在于**它用离散的表格存概率，没有泛化能力**。

神经语言模型（Neural Language Model）的突破在于：

### 6.1 词嵌入（Word Embedding）

把每个词映射到一个连续的向量（比如 300 维的实数向量），意思相近的词向量也相近。

```
向量("猫") ≈ 向量("狗")  →  它们都是宠物
向量("国王") - 向量("男人") + 向量("女人") ≈ 向量("女王")
```

这样即使没见过"量子纠缠"，因为"量子"和"原子"向量相近，模型可以借助见过"原子纠缠"的经验来推断。

### 6.2 神经网络预测下一个词

用一个神经网络替代计数表格：

```
输入：前面几个词的向量
  ↓
隐藏层：做一些非线性变换（提取特征、理解语义）
  ↓
输出层：对词汇表中每个词输出一个概率
```

关键区别：
- **N-gram**：查表（O(1) 但不能泛化）
- **神经网络**：函数拟合（可以泛化到没见过的组合）

### 6.3 从 RNN 到 Transformer

- **RNN**（2010s）：能看很长的历史，但记不住太远的东西（梯度消失）
- **LSTM/GRU**（2010s）：加了"记忆门"，好一点但还是有限
- **Transformer**（2017）：Attention 机制，能直接"看到"任意远的词 → 这就是 GPT 的基础

> 我们会在后续课程详细拆解每一个。

## 📌 一句话总结

> **语言模型就是一台根据历史文本预测下一个词的骰子机器；N-gram 用统计数数来实现它，简单粗暴但短视稀疏；神经网络用连续向量来实现它，能泛化、能记忆，最终演化为今天的大语言模型。**

## 🔑 关键术语速查

| 术语 | 含义 |
|------|------|
| **Language Model (LM)** | 语言模型，计算文本概率的模型 |
| **条件概率** $P(A\|B)$ | 在 B 已经发生的条件下 A 发生的概率 |
| **链式法则** | 联合概率 = 各条件概率的连乘 |
| **N-gram** | 只看前 N-1 个词预测下一个词的模型 |
| **Bigram** | N=2 的 N-gram，只看前 1 个词 |
| **马尔可夫假设** | 未来只依赖最近的有限历史 |
| **稀疏性 (Sparsity)** | 语料中没出现的组合概率为 0 的问题 |
| **平滑 (Smoothing)** | 给没见过的组合分配小概率的技巧 |
| **词嵌入 (Embedding)** | 把词映射到连续向量，使相似的词距离近 |
| **泛化 (Generalization)** | 模型对没见过的数据也能做出合理预测 |
