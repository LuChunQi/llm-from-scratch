# Day 9: Feed-Forward Network — Transformer 的"消化系统"

## 🔗 上节回顾

昨天我们聊了位置编码——Transformer 本身是个"路痴"，分不清"我爱你"和"你爱我"，所以我们需要用 Sinusoidal、RoPE 或 ALiBi 给它装上"方向感"。其中 RoPE 通过旋转向量来编码相对位置，成了现代 LLM 的标配。

到上节为止，Transformer 的"感知系统"已经完备了：Self-Attention 让模型知道**该看谁**，Multi-Head 让它能从**多个角度**看，位置编码让它知道**谁在哪儿**。

> ❓ **问题**：注意力机制帮模型"看到"了所有词之间的关系，但"看到"就够了吗？光看到食材，不经过加工，能变成菜吗？

今天我们进入 Transformer 的另一个核心组件——**前馈神经网络（Feed-Forward Network, FFN）**。如果 Attention 是"眼睛"，那 FFN 就是"大脑"——它负责把看到的**消化、变换、提炼**成更有意义的表示。

---

## 🧠 FFN 在 Transformer 中的位置

先来看 Transformer 一个完整 Block 的结构：

```
输入 x
  │
  ├─→ Multi-Head Attention ─→ 残差 + LayerNorm ─→ 中间表示 z
  │                                                     │
  │                              ┌──────────────────────┘
  │                              ▼
  │                        ┌──────────┐
  │                        │   FFN    │  ← 今天的主角！
  │                        └──────────┘
  │                              │
  │                              ▼
  └─→ 残差 + LayerNorm ─→ 输出
```

每个 Transformer Block 都是 **Attention → FFN** 的组合，然后各套一层残差连接和 LayerNorm。

注意：FFN 对**每个位置独立**操作。Attention 让不同位置的词互相交流，而 FFN 对每个位置的向量做**独立的非线性变换**。

打个比方：
- **Attention** 是"圆桌讨论"——大家交流信息
- **FFN** 是"回去自习"——每个人根据讨论结果独立思考、消化

---

## 🏗️ FFN 的结构

FFN 其实非常简单，就两层线性变换，中间夹一个激活函数：

```
FFN(x) = W₂ · σ(W₁ · x + b₁) + b₂
```

其中：
- `W₁`：将维度从 `d_model` 升到 `d_ff`（通常是 4 倍）
- `σ`：激活函数（如 ReLU、GELU）
- `W₂`：将维度从 `d_ff` 降回 `d_model`

### 为什么要先升维再降维？

这就像**把信息"展开"再"压缩"**：

1. **升维（d_model → 4 × d_model）**：把"浓缩"的表示展开到更高维度的空间。在更高维的空间里，更容易找到有用的特征组合。就像把一张纸折成各种形状——展开后你才能看到所有的折痕
2. **非线性变换**：激活函数（如 ReLU）在升维后的空间里做"筛选"，保留有用的、过滤没用的
3. **降维（4 × d_model → d_model）**：把提炼过的信息压缩回原来的维度，准备传给下一层

典型参数：`d_model = 512`，`d_ff = 2048`（4 倍）。现代 LLM 中这个比例可能更大（如 LLaMA 用约 8/3 倍）。

### 形象理解

想象你在做菜：
- **升维**：把食材切成小块、磨成粉、打成汁——扩展食材的"形态空间"
- **激活函数**：筛选——盐留着，坏叶子扔掉
- **降维**：把处理好的食材组合成一道菜

## ⚡ 激活函数——FFN 的灵魂

> ❓ **问题**：为什么不能就用两层线性变换，不加激活函数？不就省事了吗？

因为**两层线性变换 = 一层线性变换**。数学上，如果没有非线性激活函数：

```
W₂ · (W₁ · x) = (W₂ · W₁) · x = W' · x
```

两个矩阵相乘还是一个矩阵！增加层数毫无意义。这就是著名的 **"深度网络退化为浅层网络"** 问题。

激活函数引入**非线性**，让网络有能力学习复杂的模式。

### 1. ReLU（Rectified Linear Unit）

```
ReLU(x) = max(0, x)
```

最简单的非线性：负数变 0，正数不变。

**优点**：计算极快，梯度不会消失（正区间梯度恒为 1）
**缺点**："神经元死亡"——如果一个神经元的输出永远是负数，它就再也不更新了（梯度为 0）

### 2. GELU（Gaussian Error Linear Unit）

```
GELU(x) = x · Φ(x)  ≈  x · sigmoid(1.702x)
```

其中 Φ(x) 是标准正态分布的累积分布函数。

**直觉**：GELU 不是硬性地把负数砍成 0，而是**按概率**筛选——值越大，保留的概率越高；值越小，丢弃的概率越高。就像一个温柔的门卫，而不是一刀切的保安。

**GELU 是目前 Transformer 最主流的激活函数**，GPT、BERT、LLaMA 全都用它。

### 3. SwiGLU（Swish-Gated Linear Unit）

```
SwiGLU(x, W, V, b, c) = (xV + c) ⊙ swish(xW + b)
swish(x) = x · sigmoid(βx)
```

这是目前**最先进的 FFN 激活函数**，被 LLaMA、Qwen、DeepSeek 等现代模型采用。

它引入了一个"门控"机制——一边变换，一边决定"哪些信息该通过"。就像你有两个朋友，一个负责整理信息，另一个负责审核"这个值不值得保留"。

### 为什么 ReLU → GELU → SwiGLU？

- **ReLU** 太粗暴：直接砍掉负值，丢失信息
- **GELU** 更温和：按概率平滑筛选，减少信息损失
- **SwiGLU** 最聪明：用门控机制让网络自己学"哪些该留"

演进逻辑：从粗暴到精细，从固定规则到自适应学习。

## 🔬 FFN 到底在学什么？

> ❓ **问题**：FFN 就两层线性变换 + 激活函数，看起来这么简单，它在 Transformer 里到底承担什么角色？

这是一个非常深刻的问题。近年来的研究发现：

### FFN 是"键值记忆"

2020 年的论文 *"Transformer Feed-Forward Layers Are Key-Value Memories"* 揭示了一个惊人的发现：

FFN 的第一层权重 `W₁` 可以看作**键（Key）**，第二层权重 `W₂` 可以看作**值（Value）**。

当你输入一个词的表示时：
1. 它和 `W₁` 的每一行做内积 → 找到最"匹配"的几个键
2. 匹配到的键对应的 `W₂` 的行 → 被激发出来，加到结果中

这和 Attention 的机制惊人地相似！只不过：
- **Attention**：键和值来自**输入序列**（动态）
- **FFN**：键和值存在**权重矩阵**里（静态，训练时学到的）

所以 Transformer 的一个 Block 实际上做了**两次检索**：
1. **Attention**：从当前输入中检索相关信息
2. **FFN**：从训练好的记忆中检索相关知识

举个例子：当模型看到"法国的首都"，Attention 负责"看到"这几个词之间的关系，而 FFN 负责"回忆"起训练时学到的"法国 → 巴黎"这种知识。

### FFN 是 Transformer 的"知识库"

这也解释了为什么 FFN 占了 Transformer **约 2/3 的参数量**！模型的"知识"主要存在 FFN 的权重里，而不是 Attention 里。

## 🔑 关键洞察

1. **FFN 是 Transformer 的"消化系统"**：Attention 收集信息，FFN 加工信息。两者缺一不可
2. **先升维再降维**：升维到高维空间做非线性筛选，再压缩回来。这个"展开-压缩"的过程是提取高级特征的关键
3. **激活函数是灵魂**：没有非线性，深层网络退化为浅层。从 ReLU → GELU → SwiGLU 的演进，是从粗暴到精细的过程
4. **FFN 是 Transformer 的"知识库"**：它的权重存储了训练时学到的知识，本质上是一个键值记忆系统
5. **参数大户**：FFN 占了 Transformer 约 2/3 的参数量，模型的"知识"主要存在这里

---

## 📝 一句话总结

> FFN 是 Transformer 的"消化系统"——先升维展开，再用激活函数筛选，最后压缩回来。它占了模型 2/3 的参数，本质上是训练时积累的"键值记忆库"。

## 📖 关键术语速查

| 术语 | 含义 |
|------|------|
| **FFN** | 前馈神经网络，对每个位置独立做非线性变换 |
| **d_ff** | FFN 的中间层维度，通常是 d_model 的 4 倍 |
| **ReLU** | 最简单的激活函数：max(0, x) |
| **GELU** | 按概率筛选的激活函数，Transformer 主流选择 |
| **SwiGLU** | 带门控的激活函数，现代 LLM 的标配 |
| **键值记忆** | FFN 的本质——W₁ 是键，W₂ 是值，匹配输入输出知识 |
| **非线性** | 激活函数提供的核心能力，让深层网络有意义 |
