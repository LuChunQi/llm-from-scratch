# Day 10: Layer Normalization + 残差连接 — Transformer 的"健康通道"

## 🔗 上节回顾

昨天我们拆解了 Feed-Forward Network——Transformer 的"消化系统"。它先升维到高维空间做非线性筛选，再压缩回来，本质上是一个存储了训练知识的"键值记忆库"。FFN 占了模型约 2/3 的参数量，是 Transformer 真正的"知识仓库"。

到上节为止，我们已经认识了一个 Transformer Block 里的所有核心零件：Attention（负责"看"）、Multi-Head（多角度看）、位置编码（知道"谁在哪儿"）、FFN（负责"消化"）。但这些零件如果直接串在一起，信息在传递过程中会出问题。

> ❓ **问题**：想象一下，你要把一个口信从第 1 个人传到第 96 个人（GPT-3 有 96 层）。每个人听到的信息都经过了一次非线性变换。到最后一个人时，信息还能保持原样吗？还是会严重失真、甚至面目全非？

今天我们解决这个关键问题——**如何保证信息在深层网络中健康流动**。答案是两个搭档：**Layer Normalization** 和 **Residual Connection**。它们是 Transformer 能堆到几十层甚至上百层的基石。

---

## 🌊 梯度消失与爆炸——深层网络的噩梦

在讲解决方案之前，我们先要理解问题本身。

### 梯度消失

反向传播时，梯度要一层一层往回传。如果每层的梯度都小于 1，传了 96 层之后：

```
梯度 = 0.8^96 ≈ 0.0000002
```

梯度几乎为 0，底层参数根本不更新——网络"学不动"了。这就像一列火车，每经过一个站台就丢掉一些货物，到了终点只剩空车。

### 梯度爆炸

反过来，如果每层的梯度都大于 1：

```
梯度 = 1.2^96 ≈ 6,000,000,000,000,000
```

梯度变成天文数字，参数更新幅度巨大，训练直接崩溃。就像每个站台都往车上疯狂塞货，最后火车出轨了。

> ❓ **问题**：这两个问题本质上是同一件事——**数值不稳定**。能不能给每一层的输出"稳住"，不让它太大也不让它太小？

答案就是 **Layer Normalization**。

---

## 📏 Layer Normalization——给每层输出"调音量"

### 直觉理解

想象你在听一首歌。如果音量忽大忽小——前一句轻如耳语，后一句震耳欲聋——你根本听不清旋律。你需要一个"自动音量调节器"：不管输入的音量是多少，都把它调节到一个舒适的范围内。

**Layer Normalization 就是神经网络的"自动音量调节器"。**

它对**每一个样本**的**每一个位置**的向量，独立地做标准化：

```
LayerNorm(x) = γ ⊙ (x - μ) / σ + β
```

其中：
- `μ` = 这一个向量所有维度的**均值**
- `σ` = 这一个向量所有维度的**标准差**
- `γ`（gamma）= 可学习的缩放参数
- `β`（beta）= 可学习的偏移参数

计算步骤：
1. 算均值：`μ = mean(x)`
2. 算标准差：`σ = std(x)`
3. 标准化：`x̂ = (x - μ) / σ`（现在均值为 0，方差为 1）
4. 放缩平移：`y = γ ⊙ x̂ + β`（让网络自己学最优的分布）

### LayerNorm vs BatchNorm

你可能听过 Batch Normalization（BN），它和 LayerNorm 经常被搞混。关键区别：

| | Batch Normalization | Layer Normalization |
|---|---|---|
| **标准化维度** | 沿着 batch 方向 | 沿着 feature 方向 |
| **统计量** | 跨样本计算 | 单样本内计算 |
| **依赖 batch size** | 是（batch 太小时不稳定） | 否 |
| **序列长度变化** | 不友好 | 天然支持 |
| **推理时** | 需要保存 running mean/std | 不需要 |

**打个比方**：
- **BatchNorm** 像是"班级排名"——你的成绩跟同班同学比，不同班级的排名没有可比性
- **LayerNorm** 像是"个人均衡"——不管别人怎样，保证你各科成绩均衡发展

Transformer 选择 LayerNorm 的原因很简单：**序列长度不固定，batch size 可能很小**，BatchNorm 在这种场景下表现差。

---

## 🧮 手算 LayerNorm

用一个简单的例子来理解。假设某个位置的向量是：

```
x = [1.0, 2.0, 3.0, 4.0]
```

Step 1 — 算均值：
```
μ = (1 + 2 + 3 + 4) / 4 = 2.5
```

Step 2 — 算标准差：
```
σ = sqrt(((1-2.5)² + (2-2.5)² + (3-2.5)² + (4-2.5)²) / 4)
  = sqrt((2.25 + 0.25 + 0.25 + 2.25) / 4)
  = sqrt(1.25) ≈ 1.118
```

Step 3 — 标准化：
```
x̂ = (x - μ) / σ
   = [1.0-2.5, 2.0-2.5, 3.0-2.5, 4.0-2.5] / 1.118
   = [-1.342, -0.447, 0.447, 1.342]
```
现在均值=0，标准差=1 ✅

Step 4 — 缩放平移（假设 γ=[1,1,1,1], β=[0,0,0,0]）：
```
y = γ ⊙ x̂ + β = [-1.342, -0.447, 0.447, 1.342]
```

### γ 和 β 的作用

如果只有标准化（步骤 3），所有输出都被硬性拉到均值 0、方差 1。这可能**太限制了**——某些特征本身就需要有不同的分布。

γ 和 β 是**可学习参数**，让网络自己决定：
- γ 控制"每个维度的重要性"——重要的维度放大，不重要的缩小
- β 控制"每个维度的偏移"——给每个维度一个合适的"基准线"

所以 LayerNorm 的哲学是：**先统一规范（标准化），再让网络自己调整（γ 和 β）**。

---

## ⚡ RMSNorm——LayerNorm 的"精简版"

> ❓ **问题**：LayerNorm 好是好，但它要计算均值和标准差，还要维护 γ 和 β 两组参数。在超大模型里，能不能更省一点？

2020 年，有人提出了 **RMSNorm（Root Mean Square Normalization）**，它去掉了均值计算和 β 参数：

```
RMSNorm(x) = γ ⊙ x / RMS(x)
RMS(x) = sqrt(mean(x²))
```

**省掉了什么？**
1. 不减均值（假设均值已经接近 0）
2. 不加偏移 β（只保留缩放 γ）

**为什么可以省？** 实验表明，对 Transformer 的效果几乎没有影响！LLaMA、Qwen、DeepSeek 等现代 LLM 全都用 RMSNorm 替代了 LayerNorm。

**打个比方**：LayerNorm 像是"先搬家再装修"（先减均值，再缩放平移），RMSNorm 是"直接装修"（只缩放），省了一步但效果差不多。

## 🔗 Pre-Norm vs Post-Norm——Normalization 放在哪儿？

Transformer 原始论文把 LayerNorm 放在残差连接**之后**（Post-Norm），但后来的实践表明，放在**之前**（Pre-Norm）效果更好。

### Post-Norm（原始 Transformer）
```
x = LayerNorm(Attention(x) + x)
x = LayerNorm(FFN(x) + x)
```

### Pre-Norm（现代 Transformer，GPT/LLaMA 等）
```
x = Attention(LayerNorm(x)) + x
x = FFN(LayerNorm(x)) + x
```

**为什么 Pre-Norm 更好？**

核心原因是**梯度流动**。在 Pre-Norm 中，残差连接（下面马上讲）提供了一条**完全畅通的梯度高速公路**，梯度可以无阻碍地直接流到任意层。而 Post-Norm 中，LayerNorm 在残差路径上，会对梯度做变换，增加了训练不稳定性。

打比方：
- **Pre-Norm**：高速公路上没有收费站，一路畅通
- **Post-Norm**：每个出口都有收费站，虽然也能走，但容易堵车

## 🛤️ 残差连接——信息的"高速公路"

> ❓ **问题**：我们已经有了 LayerNorm 来稳定每层的数值。但还有一个问题——经过 96 层变换后，第 1 层的原始输入信息还能保留下来吗？

这就是 **Residual Connection（残差连接）** 要解决的问题。

### 什么是残差连接？

核心就一句话：

```
输出 = F(x) + x
```

网络层的输出 = **变换后的结果** + **原始输入**。不把输入"消化"掉，而是**留一份原件**。

### 为什么残差连接有效？

从信息角度理解：
- **没有残差**：每一层都必须把输入"完全消化"后输出，信息只能通过变换后的形式传递。如果某一层学得不好，信息就丢了
- **有残差**：每一层的输出都**至少包含原始输入**。即使 F(x) 学到的变换很小（甚至接近 0），原始信息也不会丢失

**打个比方**：你写了一份报告交给领导审批。领导如果直接在你报告上改（没有残差），一旦改错了，原文就没了。但如果领导在旁边写批注，原报告完整保留（有残差），读者可以同时看到原报告和批注。

### 从梯度角度理解

反向传播时：

```
∂Loss/∂x = ∂Loss/∂(F(x)+x) · (1 + ∂F/∂x)
```

注意那个 **`1`**！即使 `∂F/∂x` 很小（梯度消失），由于残差连接的存在，梯度**至少能原封不动地传回去**。这就像一条"保底通道"，确保梯度永远不会消失到 0。

### 残差连接是深度学习的革命

2015 年，何恺明提出的 ResNet 用残差连接把网络从 20 层推到了 **152 层**，斩获 ImageNet 冠军。这个思想后来被 Transformer 完全继承。

没有残差连接，Transformer 根本不可能堆到 96 层（GPT-3）甚至 120 层（一些更大的模型）。

---

## 🏗️ 完整的 Transformer Block

现在我们把所有零件拼起来，看一个完整的 **Pre-Norm Transformer Block**：

```
输入 x
  │
  ├───────────────────────────────────┐ （残差高速公路）
  │                                   │
  ▼                                   │
LayerNorm                             │
  │                                   │
  ▼                                   │
Multi-Head Attention                  │
  │                                   │
  ▼                                   │
  + ◄─────────────────────────────────┘ （汇合！）
  │
  │  z = Attention(LayerNorm(x)) + x
  │
  ├───────────────────────────────────┐ （另一条残差高速公路）
  │                                   │
  ▼                                   │
LayerNorm                             │
  │                                   │
  ▼                                   │
FFN                                   │
  │                                   │
  ▼                                   │
  + ◄─────────────────────────────────┘ （再次汇合！）
  │
  │  output = FFN(LayerNorm(z)) + z
  │
  ▼
输出
```

注意两个关键模式：
1. **每个子层前都有 LayerNorm**（Pre-Norm）
2. **每个子层都有残差连接**（输入直接加到输出上）

## 🔬 LayerNorm 在做什么？一个深刻的视角

> ❓ **问题**：LayerNorm 为什么能帮助训练？仅仅是"把数值调到合理范围"这么简单吗？

近年来的研究提出了一个有趣的观点：**LayerNorm 做了一种隐式的"重新缩放"（re-scaling）**。

考虑一个向量 x 经过若干层后，如果它的某个维度被放大了 100 倍。LayerNorm 会通过除以标准差把它拉回来。这意味着：

- **没有 LayerNorm**：不同层的输出尺度差异巨大，梯度要么爆炸要么消失
- **有 LayerNorm**：每一层的输出都被"归一化"到相似的尺度，梯度可以稳定传播

更重要的是，LayerNorm 让网络对**超参数（如学习率）更鲁棒**。没有它，换一个学习率可能训练就崩了；有了它，更宽的学习率范围都能工作。

## 🔑 关键洞察

1. **数值稳定性是深层网络的命脉**：没有归一化机制，梯度在几十层后要么消失要么爆炸，训练根本进行不下去
2. **LayerNorm 是"自动调音器"**：它把每一层的输出归一化到稳定的范围，让训练变得可靠
3. **RMSNorm 是 LayerNorm 的精简版**：省掉了均值计算和 β 参数，效果几乎一样，被现代 LLM 广泛采用
4. **残差连接是"信息高速公路"**：它保证原始信息在传递过程中永远不会丢失，梯度永远不会消失到 0
5. **Pre-Norm 是现代标配**：把 LayerNorm 放在子层之前（而非之后），梯度流动更顺畅
6. **一个 Transformer Block = 两套"归一化 + 变换 + 残差"**：一套给 Attention，一套给 FFN

---

## 📝 一句话总结

> Layer Normalization 是每层的"自动调音器"，保证输出数值稳定；残差连接是"信息高速公路"，确保原始信号和梯度都能无损传递。两者的组合，是 Transformer 能堆到上百层的基石。

## 📖 关键术语速查

| 术语 | 含义 |
|------|------|
| **LayerNorm** | 对单个向量的所有维度做标准化，归一化到均值 0、方差 1 |
| **RMSNorm** | LayerNorm 的简化版，只除以 RMS 值，不减均值、不加偏移 |
| **γ (gamma)** | LayerNorm 的可学习缩放参数 |
| **β (beta)** | LayerNorm 的可学习偏移参数 |
| **Pre-Norm** | LayerNorm 放在子层之前，现代 Transformer 的标准做法 |
| **Post-Norm** | LayerNorm 放在残差之后，原始 Transformer 的做法 |
| **Residual Connection** | 残差连接，输出 = 变换(x) + x，保证信息无损传递 |
| **梯度消失** | 梯度在反向传播中指数级缩小，底层参数无法更新 |
| **梯度爆炸** | 梯度在反向传播中指数级增大，训练崩溃 |
